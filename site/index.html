Get a result for the configured check, with timings, request steps and a failure class when it doesn’t pass.

Three sample outcomes. These examples do not run live checks.

RESULT / NDJSONEXAMPLE DATA

03 / INTERFACES

CLI and
HTTP API.

Run it from your terminal. Pipe the results.
Or stream them into a system of your own.

A / TERMINAL

Command-line checks

Files, directories or stdin in. Annotated text or NDJSON out. Save passing proxies with --ok-only.

proxycheck run -p basic -json proxies.txt
B / HTTP API

Results as they finish.

POST /v1/check streams NDJSON as checks finish. Your application handles storage and scheduling.

proxycheck serve -addr 127.0.0.1:8080
